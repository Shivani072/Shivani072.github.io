## 📌 Overview

**ResuMatez** empowers job seekers by enhancing resumes using real-time keyword matching from job descriptions. Our intuitive platform ensures your resume speaks the language recruiters and ATS systems are looking for.

---

## 🚀 Features

- 📄 Upload Resume (PDF/DOCX)
- 📃 Upload Job Description
- 🧠 AI-Powered Keyword Extraction
- 📊 Resume-JD Match Score
- 🔒 Secure Login/Signup System
- 💡 User-friendly, responsive UI
